Project Detail

Hater

전략적 자원 관리와 로그라이크 해금 요소를 결합해 자연스러운 다회차 플레이를 유도하는 WebGL 기반 디펜스 게임입니다.

  • 2026.05
  • Frontend · Infra
  • React · TypeScript · WebGL · AWS

Overview

Hater는 직관적인 배치와 전투 시스템을 기반으로 하면서도, 현재 스테이지에서 사용한 자원이 다음 스테이지에 영향을 주도록 설계한 로그라이크 기반 디펜스 게임입니다.

탐사/이벤트 선택지와 사령관 시스템을 통해 플레이어가 매 회차 다른 빌드를 구성하고, 리스크와 리턴을 판단하며 다음 스테이지를 준비할 수 있도록 구성했습니다.

My Role

  • FE와 Infra를 담당하며 React, TypeScript, Tailwind CSS 기반 서비스 화면과 운영 환경 구성을 함께 맡았습니다.
  • WebGL 게임 빌드를 웹에서 접근할 수 있도록 배포 환경을 구성했습니다.
  • Docker, Nginx, AWS, GitLab Runner 기반 CI/CD 흐름을 정리했습니다.

Game Systems

  • 배치와 전투 시스템은 직관적으로 구성하되, 사용한 자원이 다음 스테이지에도 유지되도록 해 자원 관리의 비중을 높였습니다.
  • 탐사/이벤트는 낮은 리턴의 안정 선택지와 하이 리스크 하이 리턴 선택지를 함께 제공해 다음 전투 운영 방향을 유저가 결정하게 했습니다.
  • 사령관 시스템은 병력 상황과 플레이 스타일에 따라 다른 패시브 효과를 제공해 다회차 빌드 경험을 강화했습니다.

Technical Highlights

WebGL 게임 빌드를 통해 별도 설치 없이 접근 가능한 웹 게임 환경을 구축했습니다. 서비스는 AWS, Nginx, Docker, GitLab CI/CD를 기반으로 배포 흐름을 정리했습니다.

게임 내부에서는 빌보드 기법을 활용해 격렬한 카메라 움직임에도 에셋이 항상 정면을 향하도록 처리하고, 디펜스 장르에서 흔하지 않은 1인칭 시점의 분위기를 강화했습니다.

Result

2026년 5월 13일 데모 버전, 5월 18일 정식 버전, 5월 20일 2.0.0 업데이트까지 진행했습니다. API 연결, 정보 공개, 통신 암호화, 밸런스 패치까지 이어지는 운영 흐름을 경험했습니다.
