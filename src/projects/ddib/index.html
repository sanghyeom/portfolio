DDIB

실시간 좌석 예매와 교환 흐름을 다루는 서비스에서 프론트엔드 주요 화면과 API 연동 구조를 구현한 프로젝트입니다.

  • 기간: 2026.01 ~ 2026.02
  • 역할: 프론트엔드 구현 및 화면 연결 안정화
  • 기술: React, JavaScript, Vite, Spring, Redis, Kafka
유튜브 영상

기여 내용

  • 프론트엔드 담당으로서 좌석 예매와 교환 서비스의 주요 화면과 사용자 흐름을 구현했습니다.
  • 좌석 상태 확인, 선택, 예매 진행 과정이 끊기지 않도록 UI와 API 연동 구조를 구성했습니다.
  • 테스트 과정에서 즉시 수정이 필요한 기능과 화면 연결 이슈를 대응하며 서비스 안정성을 높였습니다.

사용 기술

  • JavaScript
  • React
  • Vite
  • Java
  • Spring
  • Redis
  • Kafka

주요 사용자 흐름과 실제 화면 구성을 같이 볼 수 있도록 상세 페이지 안에 스크린샷 갤러리를 추가했습니다.
