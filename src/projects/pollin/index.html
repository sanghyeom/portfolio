Project Detail

Pollin

AI 기반 설문 디지털화 서비스에서 입력부터 분석 결과 확인까지 이어지는 사용자 흐름을 구성한 프로젝트입니다.

  • 2025.09 ~ 2025.12
  • Flow · Integration
  • Python · OpenAI API · Django · Vue.js

Overview

Pollin은 종이 또는 비정형 설문 내용을 디지털화하고, 분석 결과를 빠르게 확인할 수 있도록 돕는 AI 기반 설문 분석 솔루션입니다.

저는 사용자가 데이터를 입력하고, 구조화된 결과를 확인하는 흐름이 자연스럽게 이어지도록 화면과 기능 연결을 정리했습니다.

My Role

  • 데이터 입력부터 분석 결과 확인까지 이어지는 사용자 흐름을 구현했습니다.
  • OpenAI, Django, Vue 기반 기능을 연결해 설문 내용을 구조화하고 결과를 빠르게 확인할 수 있도록 구성했습니다.
  • 반복 입력과 해석 부담을 줄이는 방향으로 화면과 기능을 정리해 실사용 편의성을 높였습니다.

Problem & Solution

설문 데이터는 입력 형식이 일정하지 않으면 분석 이전 단계에서 많은 시간이 소요됩니다. 사용자가 반복적으로 내용을 정리하거나 결과를 해석해야 한다면 서비스의 효용이 떨어진다고 봤습니다.

그래서 입력 내용을 구조화하고 분석 결과를 한 흐름 안에서 볼 수 있도록 화면 전환과 기능 연결을 정리했습니다. AI 기능은 독립적인 기능이 아니라 사용자가 결과를 빠르게 확인하는 흐름의 일부로 연결했습니다.

Result

설문 입력, 구조화, 결과 확인까지 이어지는 기본 흐름을 정리해 반복 입력 부담을 줄이고, 사용자가 분석 결과를 더 빠르게 확인할 수 있는 화면 구성을 만들었습니다.

Summary

  • 핵심 기여 설문 입력, 구조화, 분석 결과 확인 흐름 구성
