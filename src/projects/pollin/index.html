Project Detail

Pollin

AI 기반 설문 디지털화 서비스에서 입력부터 분석 결과 확인까지 이어지는 사용자 흐름을 구성한 프로젝트입니다.

  • 기간: 2025.09 ~ 2025.12
  • 역할: 사용자 흐름 구현 및 기능 연동
  • 기술: Python, OpenAI API, Django, Vue.js
유튜브 영상

기여 내용

  • AI 기반 설문 디지털화 서비스에서 데이터 입력부터 분석 결과 확인까지 이어지는 사용자 흐름을 구현했습니다.
  • OpenAI, Django, Vue 기반 기능을 연결해 설문 내용을 구조화하고 결과를 빠르게 확인할 수 있도록 구성했습니다.
  • 반복 입력과 해석 부담을 줄이는 방향으로 화면과 기능을 정리해 실사용 편의성을 높였습니다.

사용 기술

  • Python
  • OpenAI API
  • Django
  • Vue.js

입력과 분석 흐름을 설명하는 상세 텍스트와 대표 화면을 한 페이지에 묶어서 바로 확인할 수 있게 구성했습니다.
